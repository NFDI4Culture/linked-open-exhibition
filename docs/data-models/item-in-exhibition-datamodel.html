Overview

An exhibition item records that one artwork was shown in one exhibition, together with the details that only the exhibition catalogue knows: catalogue number, catalogue page and the title as printed. It is the association between the Artwork model and the exhibition model.

The model is defined in wikibase-model.json. The tables below are generated from it.

Note

The field list is provisional (version 0.1).

ER Diagram

ARTWORK is shown with key fields only; see Artwork Data Model for the full entity.

Why a separate exhibition item?

A statement “artwork X was in exhibition Y” cannot hold catalogue number, page or the title as printed without qualifiers. An item of its own keeps these values together, works for artworks that appear in several exhibitions, and maps directly to CIDOC CRM (an activity that used a specific object).

CSV template

templates/exhibition-item.csv holds the exhibition items, and templates/exhibition.csv the exhibitions. Both use local ID values for repeatable loads.

File Columns
exhibition.csv exhibition_id, title, start_date, end_date, venue_id, wikidata_qid
exhibition-item.csv item_id, artwork_id, exhibition_id, catalogue_number, catalogue_page, title_as_exhibited, notes
